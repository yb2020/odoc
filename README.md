# ODOC Desktop Releases

This repository hosts public installation packages and signed update manifests
for the ODOC desktop application.

## Release channels

- **Preview**: prerelease builds for update verification and early testing.
- **Stable**: production-ready releases for general users.

Release artifacts are generated and published by the `go-sea-web` desktop
release workflow. Updater signatures are verified by the ODOC client before an
update is installed.
